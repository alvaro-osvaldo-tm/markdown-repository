# README


>	This framework is under development and is currently in the concept phase.


## Description

This is a library and application for processing Markdown repositories. It is intended to solve the following problems:

- **Governance Implementation:** Applying governance rules to Markdown documents.
- **Information Integrity:** Validating overall information integrity and equivalence between documents and information systems.
- **Link Integrity:** Maintaining the integrity of links for attachments and **document references**.
