# Solution Deliverable Concept Workflow

## Description

This workflow is to agree with stakeholder how the solution will be deliverable their acceptance criteria.

This is need to correctly deliver a solution that will fit in the organisation life and be available when the stakeholder must need to be available.

For then , this workflow have the purpose to:

- Elicit the main deliverables and milestones to be satisfied.
- Agree the project life-cycle and roadmap that will guide the solution project.

The main work product is the:

- The [Statement of Work](../../../../documents/enterprise/agreements/Statement%20of%20Work.md) with the [Project Deliverables and Acceptance](../../../../documents/enterprise/agreements/Statement%20of%20Work.md#Project%20Deliverables%20and%20Acceptance)section filled.
- The [Project Management Document](../../../../documents/management/project%20management/Project%20Management%20Document.md)
- The [Project Life-Cycle](../../../../documents/management/project%20management/Project%20Life-Cycle.md)
- The [Project Roadmap](../../../../documents/management/project%20management/Project%20Roadmap.md)
