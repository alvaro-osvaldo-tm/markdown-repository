# Setting the Stakeholder Needs and Concepts as Baseline Workflow

## Description

This workflow is destined to mark the main system concept artefacts as baseline.

It's need to be part of system configuration management to ensure a immutable snapshot of the related documents.

For then, this workflow have the purpose to:

- Define as baseline the catalogues, documents, diagrams and related artefacts.
- Identify the defined baseline as unique for further retrieval and archiving.

The main work product is the:

- The baseline identification
- The related documents set immutable in their baseline.
